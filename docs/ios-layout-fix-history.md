# iOS 布局问题修复记录

这份记录用于 iOS/Capacitor 项目复用。每次出现模拟器或真机界面异常时，记录复现设备、现象、根因、修复和验证结果。

## 2026-07-17：小屏设置页底部内容被截断

- 复现设备：iPhone 17 模拟器，iOS 26.5，窄屏尺寸。
- 现象：情侣设置页和多人设置页的内容高度超过可视区域，“开始”按钮位于屏幕底部之外；手势无法滚动到按钮。
- 根因：内容页没有明确的视口级滚动容器。内容超出后，Capacitor WebView 会把超出部分裁掉，导致页面看起来像发生溢出。
- 修复：将 `.app-shell` 设为基于 `100svh` 的滚动容器，启用触摸滚动和安全的 overscroll 行为；切换页面时同步将 `.app-shell` 滚动到顶部；在窄屏上把设置页的主要操作固定在底部安全区，避免按钮落到可视区域之外。
- 验证：重新构建 iOS Simulator 版本，并在 iPhone 17 模拟器中检查设置页；页面内容可在屏幕内滚动，底部操作区可访问。

## 后续排查顺序

1. 先在至少一个窄屏模拟器（如 iPhone SE/17）和一个大屏模拟器复现。
2. 检查是否存在固定高度、`100vh`、`overflow: hidden` 或绝对定位元素遮挡内容。
3. 页面级布局优先使用 `100svh`，超出内容放入明确的滚动容器。
4. 验证顶部刘海、底部 Home Indicator 的 safe-area 间距，以及横屏/竖屏切换。
5. 构建后同时检查模拟器截图和实际滚动/点击路径，并把结果追加到本文件。
